    relativePathTo(other: Module): List<String> (pkl.base)Source

    Returns the relative, descendent directory path between this module and other.

    Throws if no such path exists.

    For example, if module mod1 has path /dir1/mod1.pkl, and module mod2 has path /dir1/dir2/dir3/mod2.pkl, then mod1.relativePathTo(mod2) will return List("dir2", "dir3").

    A common use case is to compute the directory path between a template located at the root of a hierarchy (say rootModule.pkl) and the currently evaluated module (accessible via the module keyword):

    import "rootModule.pkl" // self-import
path = rootModule.relativePathTo(module)

    function
    Url(input: String): Url

    Constructs a Url as described by input, following RFC 3986. Accepts a URL reference (one without a scheme).

    This is lenient: whatever a component cannot hold literally is percent-encoded, and whatever is already percent-encoded is kept as is.

    Throws if input is not a valid URL.

    To test if input is a valid URL, use String.isValidUrl.

    Facts:

    net.Url("https://example.com/foo?a=1").host == "example.com"
net.Url("https://example.com/foo?a=1").query == "a=1"
net.Url("https://example.com/a b").rawPath == "/a%20b"
net.Url("/foo").scheme == null
  • expand_morelink
    function
    encodeUrlComponent(value: String): String

    Percent-encodes value so that it can be interpolated into any URL component.

    Every character other than an ASCII alphanumeric or one of -._~, the unreserved characters of RFC 3986, is percent-encoded as its UTF-8 bytes.

    Facts:

    net.encodeUrlComponent("a b&c") == "a%20b%26c"
net.encodeUrlComponent("50%") == "50%25"
  • expand_morelink
    function
    decodeUrlComponent(value: String): String

    Percent-decodes value, interpreting the decoded bytes as UTF-8.

    Throws if any % in value does not begin a percent-encoded octet. To write a literal %, encode it as %25.

    Facts:

    net.decodeUrlComponent("a%20b%26c") == "a b&c"
net.decodeUrlComponent("50%25") == "50%"
  • expand_morelink
    function
    buildQuery(parameters: Mapping<String, Listing<String>>): String

    Builds a query from parameters, for use as a Url.rawQuery.

    The result is application/x-www-form-urlencoded. A name is written once per value it holds; one that holds no values is left out entirely.

    Url.queryParameters reads back exactly the parameters given here, less any name that holds no values.

    Facts:

    net.buildQuery(new Mapping { ["q"] = new Listing { "a b" } }) == "q=a+b"
net.buildQuery(new Mapping { ["a"] = new Listing { "1"; "2" } }) == "a=1&a=2"
net.buildQuery(new Mapping { ["a"] = new Listing { "1" }; ["b"] = new Listing {} }) == "a=1"
  • expand_morelink
    function
    parseQuery(query: String): Mapping<String, Listing<String>>

    Reads query back into its parameters.

    query is read as application/x-www-form-urlencoded. A name that repeats holds the values of all its occurrences, in the order they are written. A parameter that states no = holds no value at all, and is left out.

    Throws if any % in query does not begin a percent-encoded octet.

    Facts:

    net.parseQuery("a=1&a=2") == new Mapping { ["a"] = new Listing { "1"; "2" } }
net.parseQuery("q=a+b&bare") == new Mapping { ["q"] = new Listing { "a b" } }
