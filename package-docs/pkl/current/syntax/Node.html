class Node

A generic, untyped node in the Pkl syntax tree.

Known subtypes in package:
Known usages in package:
All versions:

A node is either a leaf, carrying no children, or a branch, whose content is its children. Either way, text is the source code the node spans.

    function
    findChild(predicate: (Node) -> Boolean): Node

    Returns the first child matching predicate, searching depth-first in pre-order.

    Child means any node below this one, at any depth. This node itself is not considered. The search stops at the first match.

    Throws if no child matches predicate.

    Example:

    // the name of the first class declared in a module
module.findChild((n) -> n.type == "class").findChildOfType("identifier").text
